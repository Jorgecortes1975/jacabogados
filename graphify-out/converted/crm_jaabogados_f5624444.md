| GUÍA DE USO — CRM JA ABOGADOS |
| --- |
| CÓMO SUBIR ESTE ARCHIVO A GOOGLE SHEETS |
| 1. Abra drive.google.com en su navegador. |
| 2. Haga clic en '+ Nuevo' → 'Subir archivo' y seleccione crm_jaabogados.xlsx. |
| 3. Una vez subido, haga doble clic sobre el archivo. |
| 4. Google Sheets mostrará una barra amarilla — haga clic en 'Abrir con Google Sheets'. |
| 5. Guarde como Hoja de cálculo de Google: Archivo → Guardar como Hoja de cálculo de Google. |
| 6. Desde ahora trabaje siempre desde la versión en Google Sheets (no el .xlsx original). |
| CÓMO USAR EL CRM (Hoja '📋 CRM Prospectos') |
| • Cada fila es un prospecto. Los 17 iniciales ya están precargados con sus datos y puntajes. |
| • Columna L (ESTADO): use el menú desplegable para actualizar el estado de cada prospecto. |
| • Columnas N-U (C1 a C8): si consigue más información, actualice el puntaje (0-5) de cada criterio. |
| • Columna V (TOTAL): suma automática de C1–C8. Si ve cero, escriba la fórmula =SUMA(N3:U3) en V3 y arrastre. |
| • Columna W (SEMÁFORO): ya viene calculado. Si añade prospectos nuevos, copie la fórmula de la fila anterior. |
| • Columna K (Fecha primer contacto): registre la fecha cuando haga el primer contacto. |
| • Columna X (Próxima Acción) y Y (Fecha): actualice cada vez que defina el siguiente paso. |
| CÓMO AGREGAR UN PROSPECTO NUEVO |
| 1. Vaya a la última fila con datos en '📋 CRM Prospectos'. |
| 2. En la fila siguiente, llene los campos B a M con los datos de la empresa. |
| 3. Evalúe la empresa con la Matriz (hoja '🎯 Matriz de Evaluación') y llene C1-C8 (columnas N-U). |
| 4. Copie la fórmula de TOTAL (columna V) y SEMÁFORO (columna W) de la fila anterior. |
| 5. Asigne el estado 'Prospecto Nuevo' en la columna L. |
| FLUJO SEMANAL RECOMENDADO (30 minutos/semana) |
| Lunes:   Revisar prospectos VERDE — ¿envié el mensaje? ¿hubo respuesta? Actualizar estado. |
| Martes:  Revisar prospectos AMARILLO — aplicar secuencia de nurturing (semana 2 o 3). |
| Viernes: Agregar prospectos nuevos identificados durante la semana. Evaluar con la Matriz. |
| Fin de mes: Revisar prospectos NARANJA — ¿alguno tuvo nueva señal? ¿subir a Amarillo? |
| REGLAS DE ORO (del PDF 'Tu Buscador de Clientes Potenciales') |
| 1. Nunca inventar datos. Solo incluir información verificada en fuentes reales. |
| 2. Verificar en internet antes de contactar. Conocer la señal específica de cada empresa. |
| 3. Los mensajes son conversaciones, no ventas. Primero valor, luego oferta. |
| 4. Máximo 10-15 mensajes por día en LinkedIn para no ser marcado como spam. |
| 5. Respetar la Ley 1581/2012 (Habeas Data): no compartir esta base de datos con terceros. |
