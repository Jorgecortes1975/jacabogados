# Auditorías de Privacidad — JA Abogados

Auditoría de postura privacidad: qué datos se recopilan, dónde se transfieren, cómo se protegen, qué regulación aplica.

## Componentes de Auditoría

1. **Privacy Posture** — Página web vs Política de Privacidad vigente
   - Herramientas analíticas / cookies detectadas
   - Subprocesadores revelados (Stripe, Intercom, etc.)
   - Desviaciones de propósito
   - Categorías de datos no divulgadas

2. **Regulación Aplicable**
   - GDPR (si visitantes/clientes UE)
   - CCPA (si usuarios California)
   - LGPD (si usuarios Brasil)
   - **Ley SGDR** (Colombia) — regulación datos personales por SIC

3. **Hallazgos Críticos**
   - Cita de autoridad por cada brecha (RGPD Art. 13/14, SIC Resolución 30 de 2004, etc.)
   - Severidad (crítica / alta / media / baja)
   - Próximo paso recomendado
