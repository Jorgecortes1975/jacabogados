# Revisiones Semanales Legales — JA Abogados

Rollup semanal de actividad jurídica: qué se envió, qué está pendiente de firma, próximos deadlines, qué escala a abogado externo.

## Secciones

1. **Qué se envió esta semana** — Agrupado por dominio (contratos, compliance, asesoría, etc.)
   - Títulos + rutas de documentos
   - Status (draft, esperando feedback, etc.)

2. **Pendiente de firma**
   - Sobres DocuSign abiertos > 5 días → recordatorio educado (no enviado; draft para que tú lo envíes)
   - Estancados > 14 días → recomendación: divulgación o retracción

3. **Próximos 3 deadlines** (por urgencia)
   - Fecha límite + qué requiere + autoridad legal citada

4. **Pendiente revisión abogado**
   - Cualquier entrada sin resolver con `attorneyReviewRequired: true`
   - Breve resumen + próximo paso recomendado

5. **Recomendaciones de próximos movimientos**
   - Acciones concretas para esta semana

---

## Cadencia

- Generado automáticamente cada **lunes** (o bajo demanda)
- Incluye actividad últimos **7 días**
