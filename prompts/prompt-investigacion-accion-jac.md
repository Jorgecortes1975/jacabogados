### BLOQUE 2: INVESTIGACIÓN ESTRUCTURADA

**Mejora del original:**
```
FASE 1: MAPEAR EL PROBLEMA

PASO 1.1: Definir Alcance
└─ ¿Qué exactamente investigamos?
    ├─ Alcance amplio: Todo lo que podría afectar expansión mercantil
    ├─ Alcance estrecho: Solo datos financieros de práctica
    └─ Alcance correcto: Viabilidad + Impacto + Riesgo de expansión
        ├─ Viabilidad: ¿Tenemos recursos/experiencia?
        ├─ Impacto: ¿Qué pasaría si lo hacemos/no?
        └─ Riesgo: ¿Qué podría salir mal?

PASO 1.2: Descomponer en Preguntas Específicas
└─ Pregunta vaga: "¿Deberíamos expandir mercantil?"
    ↓ Descomponer
    ├─ VIABILIDAD: ¿Tenemos abogados con experiencia mercantil?
    ├─ VIABILIDAD: ¿Cuál es el costo de contratar / capacitar?
    ├─ MERCADO: ¿Hay demanda de servicios mercantiles en región?
    ├─ MERCADO: ¿Quiénes son competidores y qué ofrecen?
    ├─ FINANCIERO: ¿Cuál es el potencial de ingresos?
    ├─ FINANCIERO: ¿Cuál es el ROI estimado?
    ├─ RIESGO: ¿Qué pasaría si entra competidor fuerte?
    ├─ RIESGO: ¿Qué pasaría si baja la demanda?
    └─ CAPACIDAD: ¿Podemos mantener otras prácticas sin degradarse?

PASO 1.3: Agrupar por Tema
├─ TEMA 1: RECURSOS (¿Tenemos qué necesitamos?)
│   ├─ Recurso humano: Abogados, paralegales, staff
│   ├─ Recurso financiero: Presupuesto disponible
│   └─ Recurso de conocimiento: Experiencia / Track record
│
├─ TEMA 2: MERCADO (¿Es grande y accesible?)
│   ├─ Tamaño mercado: # de clientes potenciales
│   ├─ Crecimiento: ¿Mercado crece o contrae?
│   ├─ Acceso: ¿Podemos llegar a estos clientes?
│   └─ Competencia: ¿Quién más ofrece esto?
│
├─ TEMA 3: FINANCIERO (¿Es rentable?)
│   ├─ Ingresos potenciales: $/año posible
│   ├─ Costos fijos: Salarios, office, overhead
│   ├─ Costos variables: Costo por caso
│   └─ Márgenes: Ganancia neta esperada
│
├─ TEMA 4: RIESGOS (¿Qué podría fallar?)
│   ├─ Riesgo de mercado: Demanda baja
│   ├─ Riesgo operacional: Equipo no puede entregar
│   ├─ Riesgo competitivo: Competencia toma mercado
│   └─ Riesgo reputacional: Servicios de baja calidad
│
└─ TEMA 5: IMPACTO COLATERAL (¿Qué se ve afectado?)
    ├─ Impacto en otras prácticas: Atención reducida?
    ├─ Impacto en cultura: Cambio de identidad?
    └─ Impacto en empleados: Satisfacción / rotación?


FASE 2: REUNIR EVIDENCIA

Para cada pregunta, identifica: Fuentes de información

TEMA: RECURSOS - Pregunta: "¿Tenemos abogados con experiencia mercantil?"

FUENTES PRIMARIAS (Información directa):
├─ Entrevista con socio gestor: "¿Quién en equipo puede hacer mercantil?"
├─ Entrevista con abogados: "¿Experiencia previa? ¿Interés?"
├─ Revisión de CVs: Educación, experiencia, certificaciones
└─ Evaluación de casos pasados: ¿Qué tan bien manejaron temas mercantiles?

FUENTES SECUNDARIAS (Información indirecta):
├─ Benchmarking: ¿Bufetes similares qué perfil contratan?
├─ Mercado laboral: ¿Salarios para abogado mercantilista junior/senior?
├─ Educación: ¿Cursos/especialización disponibles? Costo y tiempo
└─ Track record: ¿Equipos anteriores han aprendido nuevas áreas?

FUENTES CUANTITATIVAS (Números):
├─ Costo de contratar externo: $XXK/año
├─ Costo de capacitar interno: $XK + Y meses
├─ Tiempo para estar productivo: Z meses
└─ Productividad después: X casos/año

FUENTES CUALITATIVAS (Sentimientos/Juicios):
├─ ¿Abogados entusiastas con expansión?
├─ ¿Capacidad de liderazgo existe?
├─ ¿Cultura de aprendizaje existe?
└─ ¿Riesgo de rotación si asignamos personas?

METODOLOGÍA DE RECOPILACIÓN:
├─ Entrevistas: 3-5 personas clave, 30 min cada una
├─ Encuestas: Team-wide (si privacidad lo permite)
├─ Análisis de datos: Base de casos + financiamiento
├─ Revisión documental: Reportes, casos anteriores
└─ Benchmarking: 2-3 bufetes similares


FASE 3: VALIDAR Y VERIFICAR

PASO 3.1: Triangulación
├─ Si 3 fuentes diferentes dicen lo mismo = CONFIABLE
├─ Si fuentes contradicen = Investigar discrepancia
│   └─ Ejemplo: "Abogado A dice "hay demanda", Abogado B dice "no hay"
│       Acción: ¿Bases diferentes? ¿Clientes diferentes? ¿Información desactualizada?
└─ Si solo 1 fuente dice algo = DUDAR

PASO 3.2: Lógica y Sensatez
├─ ¿La evidencia tiene sentido?
│   └─ Ejemplo: "Salarios mercantil subieron 50% en 1 año"
│       Pregunta: ¿Cambio de ley? ¿Escasez de talent? ¿Inflación?
│       Si no hay explicación → VERIFICAR más
│
├─ ¿Hay supuestos escondidos?
│   └─ Ejemplo: "Crecimiento de 35% en área", pero ¿Comparación con qué?
│       ¿2 años atrás? ¿3 años? ¿Tendencia de largo plazo?
│       Contexto cambia interpretación
│
└─ ¿Hay sesgo evidente?
    └─ Ejemplo: Socio A quiere expandir → Sus datos favorecen expansión
        Acción: Dar más peso a fuentes neutras

PASO 3.3: Buscar Contradicciones
├─ Recopilé: "Mercado mercantil crece 15%/año"
├─ Pero también: "Competencia está entrando fuerte"
├─ Resolución: ¿Mercado crece pero se fragmenta? (Más jugadores, mismo tamaño)
│   └─ Implicación: Crecimiento, pero competencia feroz
│
├─ Recopilé: "Equipo entusiasta con expansión"
├─ Pero también: "Rotación está en 25%/año (vs 10% promedio)"
├─ Resolución: ¿Entusiasmo de senior pero junior se van?
│   └─ Implicación: Cultura dividida, necesita alineación

PASO 3.4: Datos Faltantes Críticos
├─ ¿Qué información no tengo pero es crucial?
├─ ¿Es alcanzable? ¿En tiempo?
├─ Si NO es alcanzable: Indicar en recomendación
│   └─ "Análisis asume X, recomendación puede cambiar si X es falso"


FASE 4: SÍNTESIS DE HALLAZGOS

CREANDO LA NARRATIVA:

Para cada tema, resumir:

TEMA: RECURSOS
Hallazgo 1: Tenemos 2 abogados con 5+ años experiencia mercantil
├─ Evidencia: Entrevistas + CVs + 12 casos exitosos previos
├─ Confianza: ALTA
└─ Implicación: Núcleo técnico existe

Hallazgo 2: Tercio del equipo junior carece experiencia
├─ Evidencia: CVs + productividad data
├─ Confianza: MEDIA (sin feedback de clientes)
└─ Implicación: Requiere mentoría, riesgo inicial

Hallazgo 3: Capacitación externa disponible, costo $50K
├─ Evidencia: Cotizaciones de 3 programas
├─ Confianza: ALTA
└─ Implicación: Costo conocido, timeline 3-6 meses

CONCLUSIÓN TEMA: Recursos DISPONIBLES, pero requiere inversión en capacitación


TEMA: MERCADO
Hallazgo 1: Demanda de servicios mercantiles crece 15%/año en región
├─ Evidencia: Data de Cámara Comercio + encuesta 5 clientes potenciales
├─ Confianza: MEDIA-ALTA
└─ Implicación: Mercado en expansión

Hallazgo 2: Competencia: 8 bufetes, 3 de ellos grandes con presencia mercantil
├─ Evidencia: Web search + benchmarking entrevistas
├─ Confianza: ALTA
└─ Implicación: Mercado fragmented, espacio para más

Hallazgo 3: Clientes actuales piden servicios mercantiles
├─ Evidencia: 40% clientes civiles han preguntado por mercantil
├─ Confianza: ALTA
└─ Implicación: Demanda existe, clientes ya cautivos

CONCLUSIÓN TEMA: Mercado atractivo, con demanda capturable


TEMA: FINANCIERO
Hallazgo 1: Potencial ingresos $800K/año si alcanzamos 40 clientes
├─ Evidencia: Tarifa promedio $20K/caso, 40 casos/año esperado
├─ Confianza: MEDIA (asume ocupación 80%)
└─ Implicación: Ingresos significativos

Hallazgo 2: Costos iniciales: Abogado $120K + overhead $50K = $170K
├─ Evidencia: Salarios mercado + análisis overhead actual
├─ Confianza: ALTA
└─ Implicación: Margen año 1: $630K (antes impuestos)

Hallazgo 3: Break-even en mes 4-5 (asumiendo ramp-up lineal)
├─ Evidencia: Modelo financiero (ingresos vs costos por mes)
├─ Confianza: MEDIA (depende de ramp-up real)
└─ Implicación: ROI positivo en año 1

CONCLUSIÓN TEMA: Financiero viable, ROI esperado 3x inversión inicial


TEMA: RIESGOS
Hallazgo 1: Riesgo de competencia: Si Bufete X entra, puede tomar 20% clientes
├─ Evidencia: Competidor históricamente copia nuestras prácticas
├─ Confianza: MEDIA-ALTA
└─ Implicación: Viabilidad depende de velocidad de ejecución

Hallazgo 2: Riesgo operacional: Atención a litigio civil podría sufrir
├─ Evidencia: Equipo ya sobrecargado en 20% vs estándar
├─ Confianza: ALTA
└─ Implicación: Requiere contratar o redistribuir carga

Hallazgo 3: Riesgo de mercado: Regulación mercantil podría cambiar (reforma tributaria)
├─ Evidencia: Congreso analiza reforma tributaria para 2027
├─ Confianza: MEDIA (aún en propuesta)
└─ Implicación: Monitorear cambios, adaptar estrategia

CONCLUSIÓN TEMA: Riesgos son MANEJABLES con precauciones


TEMA: IMPACTO COLATERAL

├─ Evidencia: Equipo pasaría de 20% sobrecarga a 40%
├─ Confianza: ALTA
└─ Implicación: Requiere compensación (más staff o limitar crecimiento mercantil)

Hallazgo 2: Cultura de firma "litigio-céntrica" cambiaría
├─ Evidencia: Encuesta: 70% equipo se identifica con litigio
├─ Confianza: ALTA
└─ Implicación: Comunicación proactiva requerida

CONCLUSIÓN TEMA: Impacto manejable con plan de comunicación y recursos

### BLOQUE 3: IDENTIFICAR LO QUE IMPORTA

**Mejora del original:**
```
PASO 1: FILTRAR EL RUIDO

De 50 datos recopilados, ¿Cuáles 5 IMPORTAN REALMENTE?

CRITERIO: Importancia = (Impacto en decisión) × (Confianza en dato) / (Esfuerzo de verificación)

Ejemplo de scoring:

DATO A: "Competencia entra en 6 meses"
├─ Impacto en decisión: MUY ALTO (cambiaría viabilidad)
├─ Confianza: BAJA (es rumor de cliente)
├─ Esfuerzo verificación: ALTO (requiere investigación)
└─ SCORE: (10 × 3) / 8 = 3.75 → INVESTIGAR MÁS ANTES DE USAR

DATO B: "Equipo disponible puede capacitarse en 3 meses"
├─ Impacto en decisión: ALTO (timeline es crítico)
├─ Confianza: MEDIA-ALTA (programa confirma, equipo confirma)
├─ Esfuerzo verificación: BAJO (ya verificado)
└─ SCORE: (8 × 7) / 2 = 28 → USA ESTE DATO

DATO C: "Competidor A cobró $15K por caso"
├─ Impacto en decisión: BAJO (solo 1 data point sobre tarifa)
├─ Confianza: MEDIA (fuente es cliente, no confidencial de competidor)
├─ Esfuerzo verificación: MEDIO (5 más datos points podrían confirmar)
└─ SCORE: (4 × 5) / 5 = 4 → BAJO PRIORIDAD


PASO 2: ENCONTRAR LOS PATRONES

De los datos importantes, ¿Qué patrón emerge?

DATOS SOBRE RECURSOS:
├─ 2 abogados senior pueden liderar
├─ Team disponible puede capacitarse
├─ Experiencia existe parcialmente
└─ PATRÓN: Factible pero requiere inversión inicial

DATOS SOBRE MERCADO:
├─ Demanda crece 15%/año
├─ Clientes actuales piden servicios
├─ Competencia existe pero no es abrumadora
└─ PATRÓN: Mercado atractivo, ventana de oportunidad moderada

├─ Ingresos potenciales altos ($800K)
├─ Costos de inicio manejables ($170K)
├─ Break-even rápido (mes 4-5)

DATOS SOBRE RIESGOS:
├─ Competencia es amenaza, no bloqueador
├─ Operación requiere atención

└─ PATRÓN: Riesgos reales pero NO fatales

NARRATIVA EMERGENTE:
"Expansión mercantil es VIABLE. No es riesgo cero, pero viabilidad es fuerte. 
Éxito depende de ejecución rápida (primeros 6 meses son críticos antes de que 
competencia reaccione) y gestión de capacidad (equipo no puede expandir sin cuidar 
litigio civil)."


PASO 3: DISTINGUIR SEÑAL DEL RUIDO

SEÑALES (Datos que importan):
├─ Team sabe que CAN do mercantil (experiencia existe)
├─ Mercado WANTS mercantil (demanda capturable)
├─ Financieros WORK mercantil (ROI positivo)
├─ Riesgos son KNOWN y MANAGEABLE
└─ IMPLICACIÓN: Go/No-go depende de ejecución, no viabilidad

RUIDO (Datos que no importan):
├─ "Competidor X tiene oficina más grande" ← Irrelevante
├─ "Abogado Y piensa que mercantil es aburrido" ← Sesgo personal
├─ "Había demanda hace 5 años pero cambió" ← Obsoleto, hay data más reciente
└─ "Mi consultor dice que es buena idea" ← Opinion, no data

CONTRADICCIÓN A RESOLVER:
├─ Señal: "Financieramente viable"
├─ Señal: "Equipo sobrecargado"
├─ Contradicción: ¿Cómo expandir si equipo no tiene capacidad?
├─ Resolución: Opción A: Contratar más staff ANTES de expansión
│                Opción B: Limitar crecimiento mercantil a 50% del potencial
│                Opción C: Reducir litigio civil para hacer espacio
└─ Cada opción tiene trade-offs distintos


PASO 4: JERARQUIZAR POR IMPORTANCIA

1. CRITICO (Debe estar resuelto):
   ├─ ¿Equipo tiene capacidad? SÍ (con ajustes)
   ├─ ¿Mercado existe? SÍ (demanda comprobada)
   └─ ¿Es financieramente viable? SÍ (ROI positivo)

2. IMPORTANTE (Afecta plan):
   ├─ ¿Qué tan rápido pueden escalar? (3-6 meses)
   ├─ ¿Cuál es el riesgo competitivo? (Moderado, manejable)
   └─ ¿Cuánto impacta en litigio civil? (Requiere compensación)

3. CONTEXTO (Bueno saber):
   ├─ ¿Competencia es fuerte? (3 de 8 bufetes grandes)
   ├─ ¿Qué tan insatisfecho está equipo con litigio? (70% satisfecho)
   └─ ¿Hay cambios normativos esperados? (Reforma tributaria 2027)
