# Skill: Auditoría de Cumplimiento Normativo

## Objetivo

Verificar que un documento legal **cumple con todas las exigencias colombianas** antes de presentarlo ante juzgado.

Una auditoría exitosa significa: **El documento NO será devuelto por vicios de forma.**

---

## Cuándo usar esta skill

✓ **Antes de firmar cualquier escrito** (demanda, recurso, contestación)
✓ **Antes de presentar ante juzgado** (físico o SGDE)
✓ **Para revisar contratos** antes de que cliente los firme
✓ **Para validar escritos que preparan junior**
✓ **Para auditar documentos de otra rama** que no dominas

❌ **No usar para:**
- Opiniones legales (consultorías)
- Negociaciones entre partes
- Documentos internos del despacho

---

## Instrucciones paso a paso

### PASO 1: Identifica tipo de documento y rama

Llena esta tabla:

```
Tipo de documento: ☐ Demanda  ☐ Recurso  ☐ Contrato  ☐ Otro: _____
Rama del derecho: ☐ Civil   ☐ Penal  ☐ Laboral  ☐ Admin  ☐ Comercial
Procedimiento:     ☐ Ordinario ☐ Sumario ☐ Verbal ☐ Admin
Juzgado destino:   ___________________________________
```

**Consulta Skill `redaccion-legal-colombia`** para confirmación de requisitos por rama.

---

### PASO 2: Auditoría de Identificación de Partes

#### Checklist de Demandante/Demandado

Para cada parte, verifica:

```
DEMANDANTE/ACCIONANTE
☐ Nombre completo (no "Dr. García", sino "Juan García Martínez")
☐ Tipo y número de documento (C.C. 1.023.456.789, NIT 123.456.789-0)
☐ Domicilio actual (calle, número, ciudad, código postal)
☐ Ocupación/profesión (si aplica)
☐ Correo electrónico para notificaciones
☐ Teléfono de contacto

¿Falta algo? → DETENER. Añadir antes de continuar.

DEMANDADO (repite lo anterior)
☐ Nombre completo
☐ Tipo y número de documento
☐ Domicilio
☐ ¿Es persona jurídica? Si sí:
   ☐ Razón social completa
   ☐ Dígito verificador (si es NIT)
   ☐ Representante legal identificado
```

**Error frecuente:** Demanda dice "vs. La empresa X" sin nombre completo.
**Resultado:** Juzgado devuelve por defecto de forma.

---

### PASO 3: Auditoría de Normas Citadas

Para cada norma que cites:

```
Norma citada: _________________________________

Verificación:
☐ ¿Artículo existe? (verificar número correcto)
☐ ¿Está en vigencia? (no derogada)
☐ ¿Es de ley colombiana? (no extranjera)
☐ ¿Aplica a esta rama? (civil, penal, etc.)
☐ ¿Cita es textual o parafraseo? Si parafraseo:
   ☐ ¿Está aclarado ("según..." o "en términos de...")?

Formato correcto:
❌ "La ley dice que..."
❌ "El código establece..."
✓ "Código de Procedimiento Civil, Artículo 82, Ley 1564 de 2012"
✓ "Artículo 58 Código Sustantivo del Trabajo: 'El contrato...'"
```

**Repite este checklist por cada norma que cites.**

---

### PASO 4: Auditoría de Petitorio (Lo que pides)

El petitorio debe ser **CLARO y ESPECÍFICO.**

```
El juzgado debe entender exactamente qué quieres sin dudas.

❌ MALO: "Se condene al demandado a lo que sea justo"
✓ BUENO: "Se ordene al demandado ABC SAS al pago de $2.500.000 
           por concepto de honorarios profesionales no pagados"

Checklist:
☐ ¿Qué pido? (dinero, acción, omisión)
☐ ¿Cuál es el monto exacto? (si es dinero, $ específico)
☐ ¿Para qué es? (concepto: salarios, daño moral, etc.)
☐ ¿Hay intereses? Si sí:
   ☐ ¿A qué tasa? (legal, comercial, otra)
   ☐ ¿Desde cuándo? (fecha específica)
   ☐ ¿Hasta cuándo? (hasta pago, hasta sentencia, etc.)
☐ ¿Pido costas y honorarios de abogado?
   ☐ ¿Son procedentes en esta rama? (verificar código)
```

**Error frecuente:** No especificar si los intereses son desde "presentación de demanda" o desde "fecha del hecho."

---

### PASO 5: Auditoría de Hechos

Los hechos deben estar en **orden cronológico y numerados.**

```
Checklist:
☐ ¿Están numerados? (Hecho 1, Hecho 2, etc.)
☐ ¿Están en orden de tiempo? (primero lo que pasó primero)
☐ ¿Son concisos? (máx 3-5 líneas por hecho)
☐ ¿Evitan argumentación legal? (eso va en "Derecho")
☐ ¿Cada hecho tiene prueba? (no incluyo prueba aquí, pero referencia)

Ejemplo MALO:
"El demandado violó artículo 58 del código al despedir sin causa."
(esto es DERECHO, no HECHO)

Ejemplo BUENO:
"1. Demandado contrató a demandante el 01-01-2023
 2. Demandante trabajó desde entonces hasta 01-10-2025
 3. El 01-10-2025 demandado la despidió verbalmente
 4. No le entregó acta de finiquito ni prestaciones"
```

---

### PASO 6: Auditoría de Pruebas

Verifica que cada prueba esté bien documentada.

```
Para cada prueba, pregunta:

Prueba 1: ________________________________________

☐ ¿Está listada en sección "PRUEBAS"?
☐ ¿Tipo: Documento / Testigo / Pericia / Confesión?
☐ ¿Dónde está? (archivo anexo / será presentada / en juzgado)
☐ ¿Qué prueba? (qué hecho demuestra)
☐ Si es documental:
   ☐ ¿Está adjunta?
   ☐ ¿Es copia legible o original?
   ☐ ¿Tiene autenticidad clara?
☐ Si es testigo:
   ☐ Nombre completo
   ☐ Cédula
   ☐ Profesión
☐ Si es pericia:
   ☐ ¿Tipo de pericia? (contable, médica, técnica, etc.)
   ☐ ¿Solicitó designación de perito? O ¿Lo propone?

Error frecuente: Citar prueba que no existe en anexos.
Resultado: Juzgado rechaza la prueba.
```

---

### PASO 7: Auditoría de Formato Procesal

Según rama, verifica estructura completa.

#### Si es DEMANDA CIVIL (CGP):

```
☐ Encabezado: Tribunal competente / Juez / Fecha
☐ Demanda está numerada (1, 2, 3... hasta terminar)
☐ Sección "HECHOS" clara
☐ Sección "DERECHO" con citas normativas
☐ Sección "PETITORIO" específico
☐ Sección "PRUEBAS" completa
☐ Al final: Firma + rúbrica + fecha
☐ Poder del abogado (si actúa como apoderado)
   ☐ Original o copia auténtica
   ☐ Poder faculta para este tipo de demanda
   ☐ Poder no está vencido
```

#### Si es RECURSO DE APELACIÓN:

```
☐ Dirigido a tribunal que será juez de apelación
☐ Identifica sentencia impugnada (número, fecha, juez)
☐ Lista AGRAVIOS (punto por punto por qué la sentencia está mal)
☐ Cada agravio tiene norma que se violó
☐ Petitorio claro (revoque la sentencia / ordene X cosa)
☐ Dentro de plazo procesal (¿cuál es el plazo según rama?)
```

#### Si es CONTRATO:

```
☐ Título del contrato (CONTRATO DE [TIPO])
☐ Fecha clara
☐ Partes completas (nombres, documentos, domicilios)
☐ OBJETO: qué se contrata (descripción clara)
☐ PLAZO: fechas inicio y fin (o "indefinido")
☐ PRECIO: cantidad y forma de pago
☐ Cláusulas obligatorias:
   ☐ Resolución por incumplimiento
   ☐ Ley aplicable (derecho colombiano)
   ☐ Juzgados competentes (cuál ciudad)
☐ Firmas: ambas partes + testigos (si aplica)
☐ Autorización (si requiere, ej: sociedad anónima)
```

---

### PASO 8: Auditoría de SGDE (Sistema Digital)

Si se presenta ante juzgado digitalmente:

```
☐ ¿Usa SINCO u otro sistema digital? Verificar requisitos:
☐ Documento en PDF con calidad legible
☐ Firmas digitales (si requiere)
☐ Tamaño de archivo dentro de límite
☐ Nombres de archivos sin caracteres especiales
☐ Formato: NN_nombre_del_documento.pdf
☐ Adjuntos organizados (ej: Anexo_1_Contrato.pdf)
☐ Acuse de recibo esperado (dentro de X horas)

Referencia: Procedimiento P-013 Presentación SGDE
```

---

### PASO 9: Checklist de Seguridad Legal

```
☐ ¿Hay datos sensibles? (cédula, cuenta bancaria, etc.)
   → Solo si son pertinentes al caso
☐ ¿Hay confesión de cliente? (✓ bueno, protege al cliente)
☐ ¿Hay mentiras o exageraciones? (❌ malo, invalida todo)
☐ ¿Hay afirmaciones que no puedo probar? (⚠️ peligroso, juzgado lo rechaza)
☐ ¿Hay citas de confidentes sin permiso? (❌ malo, viola confidencialidad)
☐ ¿Está la firma del cliente o apoderado? (☐ sí / ☐ no → DETENER)
```

---

### PASO 10: Auditoría de Errores Comunes por Rama

#### DERECHO CIVIL:
```
❌ Error común: Demanda sin identificar competencia del juzgado
✓ Solución: Especificar "Juzgado Civil del Circuito Judicial de [ciudad]"

❌ Error: No incluir cálculo de intereses
✓ Solución: "Intereses a tasa legal desde [fecha] al [%]"

❌ Error: Petitorio ambiguo
✓ Solución: Enumerar cada cosa que pides (1. Pago de $X, 2. Costas, etc.)
```

#### DERECHO LABORAL:
```
❌ Error: No discriminar entre salarios, prestaciones e indemnización
✓ Solución: Tabla clara de cada concepto y cuantía

❌ Error: No acreditar afiliación a pensión
✓ Solución: Adjuntar comprobantes de aportes (si aplica)

❌ Error: Pedir prestaciones sin acreditar período completo
✓ Solución: Nóminas de toda la relación laboral
```

#### DERECHO PENAL:
```
❌ Error: No identificar al acusado completo
✓ Solución: Nombre, cédula, alias, domicilio, ocupación

❌ Error: Calificación jurídica incorrecta
✓ Solución: Verificar tipo penal exacto + elementos

❌ Error: No solicitar pena proporcional
✓ Solución: Pena debe ser acorde con gravedad del delito
```

## Criterios de Calidad

✓ El auditor NO es abogado del caso (perspectiva fresca)
✓ Se revisan 100% de requisitos (no saltar ninguno)
✓ Hallazgos son **específicos** (no vago, sino "Falta cédula demandado")
✓ Recomendaciones son **accionables** (puedo hacer el cambio)
✓ Veredicto es **claro** (listo / necesita correcciones / detener)

## Notas Importantes

**No confundir:**
- Auditoría de cumplimiento ≠ Revisión de fondo del caso
  - Cumplimiento = ¿Está bien escrito formalmente?
  - Fondo = ¿Tengo argumento ganador?

**Responsabilidades:**
- Abogado que redacta = Responsable de contenido legal
- Auditor = Responsable de formato + cumplimiento
- Socio = Responsable de autorizar presentación

**Escala de severidad:**
- CRÍTICO = No se puede presentar (devuelven en juzgado)
- IMPORTANTE = Se puede presentar pero debilita el caso
- RECOMENDACIÓN = Mejora pero no es obligatorio
