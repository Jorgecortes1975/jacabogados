## MATRIZ DE INTEGRACIÓN: FLUJOS DE TRABAJO

### Flujo 1: LABORAL CORPORATIVO (Despido de Ejecutivo)

```
1. ENTRADA: "CEO quiere despedir a CFO. ¿Riesgo legal?"
   ↓
2. SKILL 1.1 (Derecho Laboral Corporativo)
   → Análisis de viabilidad
   → Matriz de 8 elementos (subordinación)
   → Cálculo de exposición ($X millones)
   → Riesgos identificados
   ↓
3. SKILL 3.2 (Investigación Jurídica) — EN PARALELO
   → Línea jurisprudencial sobre despidos ejecutivos
   → Ley 2466/2025 aplicable
   ↓
4. SKILL 1.4 (Análisis Empresarial)
   → Impacto operacional (pérdida de expertise)
   → Impacto reputacional (mercado laboral se entera)
   → Impacto financiero (contingencia + costos legales)
   ↓
5. SKILL 5.1 (Traducción Ejecutiva)
   → Memo para CEO: "Riesgo MEDIO. Recomendación: Sí, con documentación rigurosa. Provisión: $X."
   ↓
6. SKILL 3.3 (Entrega)
   → Documento ejecutivo + análisis técnico completo
   → Listos para presentar a Junta
```

**Timeline Total**: 4-8 horas  
**Valor**: CEO toma decisión informada, riesgo cuantificado, roadmap claro

### Flujo 2: M&A DUE DILIGENCE (Compra de Target)

```
1. ENTRADA: "Vamos a comprar [Target]. ¿Qué riesgos legales?"
   ↓
2. SKILL 1.2 (Contratos Corporativos)
   → Review de contratos materiales de Target
   → Identificación de riesgos (terminación, cambio de control, etc.)
   ↓

   ↓
4. SKILL 1.3 (Litigio Estratégico)
   → Litigios civiles/administrativos en curso
   → Exposición financiera por cada radicado
   ↓
5. SKILL 2.1, 2.2, 2.3 (Compliance)
   → Datos personales: ¿Cumple GDPR/LGPD?
   → Tributario: ¿Posición ante DIAN? ¿Retenciones al día?
   → Corporativo: ¿Accionistas reales identificados?
   ↓
6. SKILL 3.2 (Investigación Jurídica)
   → Normativa aplicable a industria de Target
   ↓
7. SKILL 1.4 (Análisis Empresarial)
   → Síntesis: Riesgos por perspectiva (operacional, financiero, reputacional, etc.)
   ↓
8. SKILL 5.1 (Traducción Ejecutiva)
   → Data Room Report para Board: "Procede compra con precios ajustados por: [contingencias]"
   ↓
9. SKILL 3.3 (Entrega)
   → Due Diligence Report + Data Room
```

**Timeline Total**: 6-12 horas  
**Valor**: Buyer toma decisión con baseline de riesgos cuantificado; reduce sorpresas post-cierre

TIMELINE TOTAL: 2-4 HORAS (URGENCIA)

## RESTRICCIONES Y GUARDRAILS CORPORATIVOS

### 🚫 NUNCA (Non-Negotiable Rules)

1. Alucinación jurídica: Citar norma/sentencia no verificable
   - **Mitigación**: [VERIFICAR EN SUIN] obligatorio; blockhain de citas
2. Pérdida de vencimiento: Plazo procesal olvidado
   - **Mitigación**: Calendar centralizado + alertas (5 días, 1 día, fecha)
3. Conflicto de intereses: Opinar sobre caso donde bufete tiene posición adversa
   - **Mitigación**: Checklist de conflictos antes de análisis
4. Violaración de confidencialidad: Revelar información privilegiada
   - **Mitigación**: Encriptación de documentos; access control por usuario
5. Recomendación sin base: "Demandar porque es lo correcto" (sin cálculo de viabilidad)
   - **Mitigación**: Análisis financiero obligatorio antes de recomendación

### ✓ SIEMPRE (Mandatory Practices)

1. Verificación de hechos: Separar [Acreditado] / [Afirmado] / [Controvertido]
2. Cálculo de exposición: Cifras exactas con metodología, nunca "aproximadamente"
3. Consideración de alternativas: "3 opciones + trade-offs de cada una"
4. Escalation clarity: "Si X pasa, escalamos a [nombre de socio] el día [fecha]"
5. Client communication: Lenguaje de negocios, no legalés; decisión clara
