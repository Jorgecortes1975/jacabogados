# ⚡ Quick Start - 5 Minutos

## Tu primer poder en 5 minutos

### 1. Abre Claude (30 seg)
- Claude Desktop, o
- claude.ai en navegador

### 2. Verifica 2 cosas (1 min)
Settings → Capabilities
- ✅ Code Execution: ON
- ✅ File Creation: ON

### 3. Elige una tarea (30 seg)

**¿Quiero instalar superpoderes?**
→ Copia este prompt:
```
Instala estas skills del repo alirezarezvani/claude-skills:
marketing-skill, engineering-team, product-management

/plugin marketplace add alirezarezvani/claude-skills
/plugin install marketing-skill@claude-code-skills
```

**¿Quiero redactar una demanda?**
→ Abre `redactor-legal-automático.md`
→ Copia "Prompt 1: Redactar demanda civil"
→ Completa: Demandante, demandado, hechos
→ Pega en Claude

**¿Quiero investigar jurisprudencia?**
→ Abre `investigador-juridico-corporativo.md`
→ Copia "Prompt 1: Investigación jurisprudencial"
→ Completa el tema
→ Pega en Claude

### 4. Espera (2-3 min)
Claude te entrega el resultado

### 5. Usa el resultado
- ✅ Demanda: Edita nombres, firma
- ✅ Superpoder: Reinicia Claude Code
- ✅ Jurisprudencia: Verifica en SJU

---

## 3 Cosas que Debes Saber

1. **Los prompts están listos**
   No reinventes la rueda. Copia, pega, cambia [CORCHETES], listo.

2. **Tú eres el responsable**
   Claude redacta. Tú revisat, verificas, firmas.

3. **Empieza con poco**
   Usa 1 agente esta semana. No intentes todo a la vez.

## Errores Comunes (Solución Rápida)

| Error | Solución |
|-------|----------|
| "Skill no aparece" | Settings → Capabilities: ¿Code Execution y File Creation activos? |
| "Claude no responde" | ¿Conectado a internet? ¿Plan activo? |
| "Prompt no funciona" | ¿Copiaste completo? ¿Cambiaste [CORCHETES]? |
| "Jurisprudencia incorrecta" | Verifica en SJU (jurisprudencia.co) - Claude es informativo |
