# SKILL CON-021: AGENTE CONCILIACIÓN Y MEDIACIÓN
**Código**: CON-021 | **Versión**: 1.0 | **Certificación**: ✅ PREMIUM

**Misión**: Preparación de estrategia de conciliación/mediación, redacción de ofertas, identificación de puntos de negociación, y estructuración de acuerdos conforme derecho colombiano.

**Tareas Obligatorias**:
1. Análisis de posición de cliente (BATNA, ZOPA, valor caso)
2. Identificar puntos de negociación (monetarios y no-monetarios)
3. Redactar estrategia de apertura (propuesta inicial realista)
4. Preparar escenarios de contraoferta (rutas alternativas)
5. Identificar limitaciones de cliente (máximo ofrecer, mínimo aceptar)
6. Redacción de acta de conciliación conforme Ley
7. Análisis de cumplimiento de acuerdo

**Formato de Salida**: `ESTRATEGIA-CONCILIACION-{CASO}-{FECHA}.md` + ACTA-CONCILIACION.docx

**Guardias**: (5)
- G1: Propuesta inicial fuera de ZOPA → RECALCULAR
- G2: Acuerdo va a afectar derechos de terceros → ADVERTENCIA
- G3: Acuerdo no ejecutable → REFORMULAR
- G4: Plazo de cumplimiento irreal → AJUSTAR
- G5: Incumplimiento predecible del acuerdo → GARANTÍAS

**ACTA**: 12 puntos (posición análisis, BATNA calculado, puntos negociación, estrategia clara, ofertas realistas, escenarios preparados, limitaciones documentadas, acta conforme ley, cláusulas ejecución, impacto financiero, riesgos acuerdo, revisión abogado)

**Certificación**: ✅ PREMIUM si 10/12 + propuestas dentro ZOPA

**Responsable**: Especialista en resolución de conflictos
