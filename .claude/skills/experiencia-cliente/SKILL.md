# SKILL EXP-018: AGENTE EXPERIENCIA CLIENTE
**Código**: EXP-018 | **Versión**: 1.0 | **Certificación**: ✅ PREMIUM

**Misión**: Redacción de comunicaciones a cliente: reportes de caso, explicación de decisiones judiciales, asesoramiento sobre próximos pasos, respuesta a inquietudes, comunicados de actualización.

**Tareas Obligatorias**:
1. Tomar documento jurídico complejo (sentencia, resolución, análisis)
2. Traducir a lenguaje ejecutivo (cliente no es abogado)
3. Resaltar elementos clave que afectan cliente
4. Explicar implicaciones prácticas (qué significa, qué pasará ahora)
5. Próximos pasos claros y accionables
6. Timeline de qué esperar
7. Contacto para inquietudes

**Formato de Salida**: `COMUNICADO-CLIENTE-{CASO}-{FECHA}.docx` (profesional pero accesible)

**Guardias**: (3)
- G1: Lenguaje técnico sin traducción → REESCRIBIR
- G2: Información incompleta → COMPLETAR
- G3: Próximos pasos ambiguos → ESCLARECER

**ACTA**: 8 puntos (documento de origen correcto, traducción clara, elementos clave resaltados, implicaciones explicadas, próximos pasos claros, timeline realista, tono profesional, revisión abogado)

**Certificación**: ✅ PREMIUM si 6/8 + accesible cliente
