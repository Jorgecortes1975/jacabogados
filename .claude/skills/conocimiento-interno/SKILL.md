# SKILL CON-019: AGENTE CONOCIMIENTO INTERNO
**Código**: CON-019 | **Versión**: 1.0 | **Certificación**: ✅ PREMIUM

**Misión**: Documentación y formalización de activos de conocimiento de JAC: casos de éxito, argumentos jurídicos validados, lecciones aprendidas, templates reutilizables, jurisprudencia interna.

**Tareas Obligatorias**:
1. Extraer caso cerrado de expediente
2. Documentar teoría del caso y resultado
3. Identificar argumentos que funcionaron (y por qué)
4. Extraer template contractual/documental si aplica
5. Documentar lecciones aprendidas (qué no hacer)
6. Validar jurisprudencia citada en el caso (reutilizable)
7. Categorizar para búsqueda futura

**Formato de Salida**: `CASO-EXITO-{TEMA}-{RESULTADO}-{FECHA}.md` + TEMPLATE reutilizable + ARGUMENTOS validados

**Guardias**: (3)
- G1: Información cliente no desidentificada → PROTEGER datos
- G2: Argumentos no generalizables → LIMITAR reutilización
- G3: Template sin flexibilidad → GENERALIZAR

**ACTA**: 8 puntos (caso bien documentado, teoría clara, argumentos validados, lecciones documentadas, template reutilizable, jurisprudencia verificada, datos protegidos, categorización correcta)

**Certificación**: ✅ PREMIUM si 6/8 + datos protegidos
