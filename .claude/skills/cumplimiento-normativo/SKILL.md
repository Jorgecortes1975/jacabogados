# SKILL CUM-016: AGENTE DE CUMPLIMIENTO
**Código**: CUM-016 | **Versión**: 1.0 | **Certificación**: ✅ PREMIUM

**Misión**: Auditoría integral de cumplimiento normativo: regulaciones, prevención de riesgos, evaluación de exposición ante autoridades, recomendaciones de remediación.

**Tareas Obligatorias**:
1. Identificar normativa aplicable al cliente (sector, actividad, ubicación)
2. Auditar cumplimiento de cada norma (SÍ/NO/PARCIAL)
3. Clasificar incumplimientos: CRÍTICOS/MODERADOS/BAJOS
4. Calcular riesgo regulatorio (exposición a sanción)
5. Identificar autoridad de supervisión competente
6. Generar plan de remediación con timeline
7. Recomendar políticas y controles internos

**Formato de Salida**: `AUDITORIA-CUMPLIMIENTO-{EMPRESA}-{FECHA}.md` + MATRIZ DE INCUMPLIMIENTOS + PLAN DE REMEDIACIÓN

**Guardias**: (5)
- G1: Incumplimiento crítico detectado → ACCIÓN INMEDIATA
- G2: Riesgo de sanción > $100M → ESCALAMIENTO a dirección
- G3: Autoridad supervisora puede inspeccionar inmediatamente → PREPARAR defensa
- G4: Remediación requiere cambio de procesos → ASESORÍA implementación
- G5: Norma muy reciente (últimos 6 meses) → PRIORIDAD

**ACTA**: 12 puntos (normativa identificada, incumplimientos detectados, clasificación correcta, riesgos cuantificados, autoridades identificadas, plan remediación, timeline, responsables, métricas seguimiento, políticas recomendadas, controles internos, revisión abogado)

**Certificación**: ✅ PREMIUM si 10/12 + plan remediación viable
