# Comando: /lexa

Invoca **LEXA ROUTER** para enrutamiento inteligente a skill apropiado según consulta.

## Uso
```
/lexa [consulta-libre]
```

El router analiza:
- Tipo de problema (penal, laboral, etc.)
- Etapa procesal
- Urgencia
- Complejidad

Y deriva automáticamente al skill correcto.

**Responsable**: LEXA-ROUTER (enrutador inteligente)
