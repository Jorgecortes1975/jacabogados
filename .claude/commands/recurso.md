# Comando: /recurso

Invoca **REC-007 (Asesor Recursos Apelación)** para redacción de recursos judiciales.

## Uso
```
/recurso [tipo-recurso] [sentencia-numero]
```

## Recursos
- reposicion: Ante misma autoridad
- apelacion: Ante tribunal superior
- casacion: Ante corte suprema
- habeas-corpus: Libertad personal

**Responsable**: REC-007 Especialista Recursos
