# Comando: /demanda

Invoca **JAC-SK-009 (Demanda Profesional)** para redactar demandas conforme Protocolo Alta Corte.

## Uso
```
/demanda [tipo-proceso] [acción] [cuantía]
```

## Tipos disponibles
- civil (responsabilidad, incumplimiento)
- laboral (reintegro, prestaciones)
- administrativo (nulidad acto)
- penal (acusación)

## Salida
Demanda completa + fundamentos jurídicos + OSCOLA

**Responsable**: Redactor Premium + Anti-Hallucination v4.2
