# Comando: /privacidad

Invoca asesoría en privacidad y protección de datos: LSRLOPD, GDPR.

## Uso
```
/privacidad [tipo-consulta] [empresa]
```

## Consultas
- politicas: Redacción política privacidad
- tratamiento: Análisis tratamiento datos
- incidente: Notificación brecha
- compliance: Auditoría LSRLOPD

**Responsable**: Privacy Legal Specialist
