# Comando: /marketing

Invoca **COM-017 (Agente Comercial)** para contenido institucional y posicionamiento.

## Uso
```
/marketing [tipo-contenido] [tema]
```

## Tipos
- articulo-blog: Análisis legal tema
- guia-cliente: Guía práctica
- comunicado: Press release
- caso-exito: Publicación caso

**Responsable**: COM-017 + RED-010
