# Comando: /notebooklm

Invoca integración con NotebookLM para investigación y síntesis de documentos complejos.

## Uso
```
/notebooklm [documento] [tipo-analisis]
```

## Análisis
- resumen: Síntesis documento
- qa: Preguntas y respuestas
- cronologia: Timeline eventos
- indices: Índice temático

**Nota**: Requiere notebooklm-mcp-cli instalado

**Responsable**: NotebookLM + Investigador
