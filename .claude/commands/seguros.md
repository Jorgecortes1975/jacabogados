# Comando: /seguros

Invoca **INS-030 (Asesor Derecho de Seguros)** para reclamaciones y defensa ante aseguradoras.

## Uso
```
/seguros [tipo-siniestro] [aseguradora]
```

## Siniestros
- responsabilidad-civil: Cobertura RC
- daños: Incendio, robo, todo riesgo
- vida: Beneficiarios
- accidentes: SOAT + responsabilidad

**Responsable**: INS-030 Especialista Seguros
