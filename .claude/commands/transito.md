# Comando: /transito

Invoca **TRX-031 (Asesor Derecho de Tránsito)** para infracciones y accidentes viales.

## Uso
```
/transito [tipo-caso] [placa]
```

## Casos
- infraccion: Defensa multa
- accidente: Responsabilidad civil
- retencion: Liberación vehículo
- licencia: Suspensión/rehabilitación

**Responsable**: TRX-031 Especialista Tránsito
