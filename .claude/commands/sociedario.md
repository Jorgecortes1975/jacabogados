# Comando: /societario

Invoca **SOC-014 (Asesor Derecho Societario)** para governance y operaciones corporativas.

## Uso
```
/societario [operacion] [empresa]
```

## Operaciones
- governance: Actas asambleas, juntas directivas
- fusion: Análisis impacto, documentación
- escision: Estructuración legal
- liquidacion: Plan liquidación

**Responsable**: SOC-014 + Compliance
