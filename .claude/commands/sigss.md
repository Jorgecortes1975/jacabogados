# Comando: /sigss

Invoca asesoría en SIGSS (Sistema Integrado de Información Seguridad Social).

## Uso
```
/sigss [tipo-consulta] [afiliado]
```

## Consultas
- cotizacion: Verificación cotizaciones
- periodo: Análisis períodos cotización
- prestacion: Cálculo prestación
- recurso: Defensa ante UGPP

**Responsable**: Especialista SIGSS
