# Comando: /ugpp

Invoca asesoría en UGPP (Unidad de Gestión Pensional y Parafiscal).

## Uso
```
/ugpp [tipo-consulta] [fondo]
```

## Consultas
- afiliacion: Trámite afiliación
- aporte: Cálculo aportes
- beneficio: Disponibilidad beneficio
- reclamo: Defensa ante negativa

**Responsable**: Especialista UGPP
