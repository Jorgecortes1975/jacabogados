# COMANDO: /ronda

## Qué Hace

Dispara un ciclo completo de prospección:
1. Busca leads con Apify
2. Enriquece datos (correos, teléfono)
3. Califica por grado (A, B, C)
4. Escribe correos listos para mandar
5. Deja reporte de toda la operación

## Cómo Usarlo

```bash
/ronda
```

O con argumentos (opcional):

```bash
/ronda bogota
/ronda medellin
/ronda sector:comercio
```

## Ejecución Paso a Paso

### Paso 1: Lee Memoria Permanente

- Lee: `CLAUDE-agente-prospection.md` (quién eres, presupuesto, reglas)
- Lee: `perfil-cliente.md` (a quién buscas)
- Lee: `memoria/bitacora.md` (rondas anteriores, qué funcionó)
- Lee: `memoria/ya-contactados.csv` (a quién ya tocaste)
- Lee: `memoria/no-contactar.csv` (quiénes dijeron que no)

### Paso 2: Decide Qué Buscar Hoy

Si el usuario pasó un argumento (ciudad/sector), úsalo.
Si no, usa la próxima búsqueda de la lista de perfil-cliente.md.

Ej: "Hoy vamos con Bogotá, empresas comerciales, 10-50 empleados"

### Paso 3: Corre el Skill "Sacar-Leads"

Invoca `.claude/skills/sacar-leads.md`:

1. Elige actor Apify
2. Arma parámetros exactos
3. **Calcula costo y pide aprobación (espera OK)**
4. Corre el actor
5. Extrae a CSV: `leads/YYYY-MM-DD.csv`
6. Devuelve reporte: "traídos 30, costo $0.15"

### Paso 4: Corre el Skill "Enriquecer-Leads"

Invoca `.claude/skills/enriquecer-leads.md`:

1. Abre `leads/YYYY-MM-DD.csv`
2. Identifica huecos (correo, teléfono, redes)
3. **Estima costo por lote y pide aprobación (espera OK)**
4. Corre actores de enriquecimiento
5. Fusiona datos al CSV
6. Devuelve reporte: "30 → 28 con correo, costo $0.20"

### Paso 5: Califica Leads

Lee perfil-cliente.md y asigna grado:

**Grado A:**
- Cumple 4+ señales de calificación
- Tiene correo de confianza alta o media
- Es claro a quién contactar

**Grado B:**
- Cumple 2-3 señales
- Tiene correo pero confianza baja, O tiene teléfono
- Requiere seguimiento más cuidado

**Grado C:**
- Apenas roza el perfil
- Puede servir pero probabilidad baja
- Se contacta solo si quedan recursos

Agrega columna `grado` al CSV.

### Paso 6: Corre el Skill "Escribir-Correos"

Invoca `.claude/skills/escribir-correos.md`:

1. Filtra grado A y B (solo con correo de confianza media/alta)
2. Para cada uno: identifica ángulo real
3. **Muestra 3 ejemplos y espera aprobación (espera OK)**
4. Escribe el resto
5. Guarda: `correos/YYYY-MM-DD.csv`
6. Devuelve reporte: "28 contactos → 24 con correo → 22 correos escritos"

### Paso 7: Registro en Memoria

**Actualiza** `memoria/ya-contactados.csv`:
```
negocio | fecha | fuente | grado
Empresa X | 2026-09-21 | ronda-1 | A
```

**Crea entrada** en `memoria/bitacora.md`:
```
## Ronda 2026-09-21
- Búsqueda: Bogotá, comercio, 10-50 empleados
- Leads traídos: 30
- Con correo: 28
- Grado A: 12
- Grado B: 10
- Costo: $0.35 USD
- Correos escritos: 22 (pendientes aprobación)
- Resultado: ✅ OK
```

### Paso 8: Genera Reporte Final

**Archivo:** `reportes/ronda-YYYY-MM-DD.md`


## Reglas Inquebrantables Durante /ronda

✋ **Nunca manda correos.** Solo escribe borradores.

💰 **Siempre pide OK antes de gastar.** Calcula costo, muestra número, espera respuesta.

📝 **Nunca inventa datos.** Lo que no trae Apify va como "sin dato".

🔐 **Respeta memoria.** No repitas contactos de ya-contactados.csv ni no-contactar.csv.

📊 **Detente si <50% califica.** Si menos del 50% cumple señales, avisa y propone cambiar búsqueda.

⏸️ **Respeta PAUSA.** Si existe archivo `PAUSA` en raíz, solo registra en bitácora que estabas pausado.

💵 **Respeta presupuesto.** Si llegarías a límite mensual, detente y avisa.

---

## Qué Pasa Si Algo Se Rompe

| Problema | Acción |
|----------|--------|
| Actor de Apify falla | Anota en reportes/, propone reintentar o cambiar actor |
| <50% de contactos califican | Detente, no gastes más, propone cambiar búsqueda |
| Gasto se pasaría del presupuesto | Detente, avisa en reporte, propone limitar siguiente ronda |
| Correo rebota mucho | Marca como "no confiar" en confianza, propone verificar datos |
| Se acabó memoria en disco | Comprime archivos viejos (>3 meses) a descartados/ |
