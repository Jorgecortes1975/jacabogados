# Comando: /ambiental

Invoca **ENV-029 (Asesor Derecho Ambiental)** para licencias y cumplimiento regulatorio.

## Uso
```
/ambiental [tipo-proyecto] [ubicacion]
```

## Proyectos
- licencia: Análisis viabilidad licencia
- operacion: Auditoría compliance
- siniestro: Defensa ante acto ANLA
- remedializacion: Plan remediación

**Responsable**: ENV-029 Especialista Ambiental
