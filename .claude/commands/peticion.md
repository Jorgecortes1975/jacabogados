# Comando: /peticion

Invoca **DPE-020 (Derechos de Petición)** para redacción de derechos ante entidades públicas.

## Uso
```
/peticion [tipo-solicitud] [entidad]
```

## Tipos
- acceso-info: Derecho acceso información
- reclamo: Protesta administrativa
- tutela: Acción tutela
- popular: Acción popular

**Responsable**: DPE-020 Especialista Admin.
