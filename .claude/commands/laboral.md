# Comando: /laboral

Invoca **LAB-013 (Derecho Laboral & Seguridad Social)** para contratación y conflictos trabajo.

## Uso
```
/laboral [tipo-consulta] [empresa]
```

## Tipos
- contrato: Análisis/redacción contrato
- afiliacion: Verificación seguridad social
- conflicto: Estrategia defensa
- prestaciones: Cálculo liquidación

**Responsable**: LAB-013 Especialista Laboral
