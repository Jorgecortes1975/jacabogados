# Comando: /compliance

Invoca **CUM-016 (Cumplimiento Normativo)** para auditoría integral regulatoria.

## Uso
```
/compliance [area] [empresa]
```

## Áreas
- laboral: Normativa laboral
- ambiental: Licencias y permisos
- tributaria: DIAN compliance
- financiera: Normativa SFC

**Responsable**: CUM-016 Especialista Compliance
