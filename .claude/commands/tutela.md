# Comando: /tutela

Invoca **COS-022 (Derechos Constitucionales)** para acciones de tutela.

## Uso
```
/tutela [derecho-vulnerado] [entidad]
```

## Derechos
- vida: Protección vida
- libertad: Libertad personal
- privacidad: Protección datos
- debido-proceso: Garantías procesales

**Responsable**: COS-022 Especialista Constitucional
