# Comando: /penal

Invoca **PEN-027 (Asesor Derecho Penal)** para defensa penal y análisis imputación.

## Uso
```
/penal [delito] [etapa-procesal]
```

## Etapas
- investigacion: Análisis imputación
- acusacion: Estrategia defensa
- juicio: Alegatos + pruebas
- sentencia: Recursos apelación/casación

**Responsable**: PEN-027 Especialista Penal
