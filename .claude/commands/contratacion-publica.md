# Comando: /contratacion-publica

Invoca asesoría en contratación pública: normativa, pliegos, recursos.

## Uso
```
/contratacion-publica [tipo-procedimiento] [entidad-contratante]
```

## Procedimientos
- licitacion: Análisis pliego
- seleccion-abierta: Observaciones
- menor-cuantia: Procedimiento
- convenio: Vigencia normativa

**Responsable**: Especialista Contratación Pública
