# Comando: /tributario

Invoca **TAX-028 (Asesor Derecho Tributario)** para análisis de obligaciones fiscales y DIAN.

## Uso
```
/tributario [tipo-consulta] [período]
```

## Tipos
- liquidacion: Cálculo IR/IVA
- requerimiento: Defensa ante DIAN
- operacion: Impacto tributario fusión/liquidación
- planificacion: Estrategia legal

## Salida
Análisis completo + matrices + escrito defensa si procede

**Responsable**: TAX-028 + Especialista CPA
