# Comando: /due-diligence

Invoca auditoría integral de empresa: legal + fiscal + laboral + compliance.

## Uso
```
/due-diligence [empresa] [tipo-operacion]
```

## Tipos
- adquisicion: Pre-compra auditoria
- fusion: Pre-fusión análisis
- inversion: Due diligence inversor
- credito: Verificación bancaria

**Responsable**: Multi-skill coordinado
