# Comando: /investigar

Invoca búsqueda exhaustiva de normativa y jurisprudencia verificada.

## Uso
```
/investigar [tema-legal] [jurisdiccion]
```

## Salida
- Normas vigentes con artículos específicos
- Jurisprudencia pacífica (OSCOLA citations)
- Matriz de confianza ALTA/MEDIA/BAJA
- Análisis aplicable al caso

**Responsable**: LEXIUS-026 + Anti-Hallucination v4.2
