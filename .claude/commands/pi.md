# Comando: /pi

Invoca asesoría en Propiedad Intelectual: marcas, patentes, derechos autor.

## Uso
```
/pi [tipo-proteccion] [activo]
```

## Protecciones
- marca: Registro/vigilancia marca
- patente: Solicitud patente
- derechos-autor: Licencias software
- secreto-comercial: Protección confidencial

**Responsable**: Especialista PI
