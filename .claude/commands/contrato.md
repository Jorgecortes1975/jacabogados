# Comando: /contrato

Invoca **CON-012 (Asesor Redacción Contractual)** para revisión y redacción contratos.

## Uso
```
/contrato [tipo-contrato] [partes]
```

## Tipos
- laboral: Contrato indefinido/fijo
- compraventa: Bienes/servicios
- prestamo: Crédito/garantías
- arrendamiento: Inmuebles/muebles
- internacional: Multi-jurisdiccional

**Responsable**: CON-012 + RED-010
