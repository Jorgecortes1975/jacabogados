# Comando: /auditar

Invoca **AUD-011 (Auditor Calidad)** para realizar auditoría integral de documentos antes de entrega cliente.

## Uso
```
/auditar [documento-path] [tipo-auditoria]
```

## Tipos de auditoría disponibles
- `calidad-integral`: ACTA 16 puntos, Guardias automáticas, Test Suite
- `redaccion`: Protocolo Alta Corte, lenguaje magistral, OSCOLA
- `legalidad`: Verificación 100% normativa y jurisprudencia
- `formato`: Estructura, plantillas, consistencia

## Salida
✅ APROBADO / ❌ RECHAZADO + correcciones específicas

**Responsable**: AUD-011 Auditor Calidad Pre-Entrega
