## 🎯 OBJETIVO

Reportar en el Sistema Único de Información (SUI) las nóminas CORREGIDAS con las bases de cotización ajustadas (incluyendo comisiones).

**¿Por qué es obligatorio?**
- Ley 100/1993: Empresas deben reportar aportes a sistemas de seguridad social
- Resolución 3165/2002: Define periodicidad (mensual)
- Multa por incumplimiento: 5-10 UVT ($225K-$450K)

**Columnas requeridas** (verificar formato actual de SUI):
```
NIT Empresa | Afiliado | Nombre Afiliado | Cédula | Salario Base | Comisiones | 
Base Total Cotización | EPS | AFP | ARL | Caja | Período
```

### Subir Nómina de Junio

1. En panel SUI → "Reportar Nómina"
2. Seleccionar período: **Junio 2026**
3. Descargar formato si es necesario
4. Llenar con datos corregidos:
   - [ ] Todos los 15 empleados

## ✅ FASE 4: VALIDACIÓN Y REVISIÓN (Día 2-3)

### SUI Valida Automáticamente

Después de subir, SUI revisa:
- [ ] Formatos correctos
- [ ] Campos obligatorios llenos
- [ ] Bases de cotización lógicas
- [ ] Sin inconsistencias

**Posibles errores**:

| Error | Causa | Solución |
|-------|-------|----------|
| "Salario menor a mínimo legal" | Base < $1.750.905 | Validar nómina, puede haber error |
| "Falta campo obligatorio" | No incluye comisión | Llenar comisión en columna correcta |
| "Afiliado duplicado" | Empleado aparece 2× | Eliminar línea duplicada |
| "Período no permitido" | Mes ya reportado | Contactar SUI si hay error previo |

**Si hay errores**:
- [ ] Corregir en Excel
- [ ] Resubir archivo
- [ ] Obtener nuevo radicado

**Si no hay errores**:
- [ ] SUI acepta
- [ ] Envío confirmado
