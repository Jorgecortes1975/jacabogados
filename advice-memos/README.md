# Memoranda Jurídicas de Asesoría — JA Abogados

Respuestas rápidas (~200–400 palabras) a preguntas legales de clientes. Cada memo:

1. **Pregunta** — Resumida en un párrafo
2. **Respuesta corta** — "Sí", "No", o "Depende — regla X"
3. **Contexto** — Por qué aplica a este cliente (etapa, geografía, reguladores)
4. **Fuentes citadas** — Leyes/Decretos/Resoluciones SIC/Superfinanciera/INVIMA, en línea
5. **Próximo paso** — Acción concreta ("Presenta DPA", "Contacta asesor fintech", etc.)
6. **Escalación** — Si toca regulación sensible: `attorneyReviewRequired: true`

---

## Formato de Archivo

```
{slug}-{YYYY-MM-DD}.md
```

Ejemplo: `do-i-need-data-processing-agreement-2026-08-02.md`

---

## Checklist

- [ ] Pregunta parafraseada fielmente
- [ ] Respuesta corta en primer párrafo
- [ ] Contexto colombiano (Código Civil/Comercio, reguladores aplicables)
- [ ] Citas en línea (no hedge; si "depende" → explicar regla)
- [ ] Próximo paso claro
- [ ] Escalación marcada si: fintech, medtech, aeronáutica, laboral colectiva, tributaria, penal corporativo
