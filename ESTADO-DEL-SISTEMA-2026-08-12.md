## 🚀 Cómo Usar

### Para Instalación (Windows)

```bash
# 1. Click derecho en instalacion-jac/INSTALAR.bat
# 2. "Ejecutar como administrador"
# 3. Esperar a que termine

# 4. Configurar PowerShell
New-Item -Path $PROFILE -Type File -Force | Out-Null
Copy-Item ".\instalacion-jac\profile.ps1" $PROFILE -Force

# 5. Probar comandos
audit "Mi Caso"
legal "jurisprudencia"
sync-downloads
alerts check
```

### Para Activar Agentes (Linux/Mac)

```bash
# Ver agentes disponibles
ls .claude/agents/

# Activar sistema completo
node .claude/scripts/activate-automation.js

# Ver status
node .claude/scripts/loop-status.js
```
