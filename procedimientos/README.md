## Estándares de Documentación

Cada procedimiento incluye:

- **Objetivo:** ¿Qué se logra?
- **Alcance:** Quién participa
- **Paso a Paso:** Instrucciones numeradas y claras
- **Excepciones:** Casos especiales
- **Métricas:** Cómo medir éxito
- **Checklist:** Verificación al final
- **Contacto:** Quién pregunta si hay dudas

---

## Actualización de Procedimientos

Cuando descubras que un procedimiento:
- **Está obsoleto** → Crea issue en repo con tag `procedimiento-obsoleto`
- **Tiene gaps** → Documenta el gap y propón mejora
- **Falla** → Reúnete con responsable, actualiza wiki, comunica cambio al equipo

**Ciclo de revisión:** Trimestral (mes 1, 4, 7, 10)

## Preguntas Frecuentes

**P: ¿Debo seguir exactamente cada paso?**  
R: Sí, salvo que el caso requiera excepción documentada. Entonces documenta la excepción.

**P: ¿Quién actualiza los procedimientos?**  
R: Quien los ejecuta. Si algo cambió, actualiza la wiki el mismo día.

**P: ¿Hay versiones antiguas de procedimientos?**  
R: Git guarda el historial. Pregunta a ops si necesitas versión anterior.
