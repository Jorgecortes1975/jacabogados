# JA ABOGADOS — SISTEMA DE SERVICIOS CORPORATIVOS

**Especialidad**: Seguridad Social y Derecho Laboral para PYMEs Colombia  
**Ubicación**: Medellín, Antioquia  
**Creado**: Julio 2026

Este repositorio contiene:
- 📋 Memoria del sistema (CLAUDE.md)
- 📖 Guía de uso paso a paso
- 📄 Templates automáticos para contratos, políticas y checklists
- 📚 Base de normativa actualizada (CST, Ley 100, Decreto 1072, etc.)
- 🤖 Prompts para automatizar análisis con Claude

## Inicio Rápido

1. Lee `CLAUDE.md` — memoria permanente del sistema
2. Lee `GUIA-USO.md` — flujo paso a paso
3. Para nuevo cliente: copia template de Intake de `templates/`
4. Para análisis: usa prompts de `prompts/` con Claude
